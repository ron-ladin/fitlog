# יומן כושר — מדריך התקנה לאייפון

אפליקציית ווב (PWA) לשימוש אישי: אימוני כוח לפי תבניות, ריצות, תזונה וסטטיסטיקות.
חינמית לגמרי, בלי שרת, בלי התחברות ובלי AI. כל הנתונים נשמרים **על האייפון בלבד**.

## שלב 1 — להעלות את התיקייה לאתר חינמי (פעם אחת, כ-5 דקות)

כדי שהאייפון יוכל להתקין את האפליקציה היא צריכה כתובת אינטרנט (https).
הדרך הפשוטה ביותר — **GitHub Pages** (חינם, בלי כרטיס אשראי):

1. היכנס ל-github.com ופתח חשבון חינמי (אם אין לך).
2. לחץ על **+** למעלה ← **New repository**. תן שם, למשל `fitlog`, בחר **Public**, ולחץ **Create repository**.
3. בעמוד שנפתח לחץ על הקישור **uploading an existing file**.
4. גרור לחלון את **כל התוכן של תיקיית `fitlog`** (כל הקבצים, כולל `foods-il.json`, ואת התיקיות `icons` ו-`vendor`) ולחץ **Commit changes**.
5. עבור ל-**Settings** ← **Pages**. תחת *Branch* בחר `main` ו-`/ (root)` ולחץ **Save**.
6. אחרי דקה-שתיים תופיע למעלה הכתובת, משהו כמו `https://<שם-המשתמש>.github.io/fitlog/`.

> חלופה: Netlify (app.netlify.com/drop) — גוררים את התיקייה ומקבלים כתובת. צריך לפתוח חשבון חינמי כדי שהאתר לא יימחק.

## שלב 2 — להתקין על מסך הבית

1. פתח את הכתובת ב-**Safari** באייפון (חייב Safari).
2. לחץ על כפתור **השיתוף** (ריבוע עם חץ למעלה).
3. גלול ובחר **הוספה למסך הבית** ← **הוסף**.

זהו. האפליקציה תופיע עם אייקון משלה, תיפתח במסך מלא בלי שורת כתובת, ותעבוד גם בלי אינטרנט.

## חשוב לדעת

- **הנתונים שמורים רק בטלפון.** מחיקת האפליקציה ממסך הבית מוחקת גם את הנתונים.
  כדאי מדי פעם: ⚙️ הגדרות ← **ייצוא גיבוי** ← לשמור ב-iCloud Drive / קבצים. אפשר לשחזר עם **ייבוא גיבוי**.
- **אל תשנה את הכתובת** אחרי שהתחלת להשתמש — הנתונים קשורים לכתובת. אם חייבים: ייצא גיבוי, התקן מהכתובת החדשה, ייבא.
- **עדכונים:** אם משנים קבצים ומעלים שוב ל-GitHub, האפליקציה בטלפון תתעדכן לבד בפתיחה הבאה כשיש אינטרנט.

## מה יש באפליקציה

- **כוח** — תבניות אימון (שם, סוג: רגליים / פלג גוף עליון / גוף מלא / ליבה / אחר, תרגילים ומספר סטים).
  "התחל אימון" ממלא אוטומטית את המשקלים מהפעם הקודמת ומציג מה עשית אז. האימון נשמר תוך כדי הקלדה, כך שאפשר לסגור את האפליקציה באמצע.
  אפשר גם אימון חופשי, ועריכה/מחיקה של אימונים ישנים.
- **ריצה** — תאריך, מרחק, זמן; חישוב קצב אוטומטי, סיכום חודשי והיסטוריה.
- **תזונה** — קלוריות, חלבון, פחמימות ושומן מול יעד יומי:
  - **חיפוש** במאגר התזונה הלאומי של משרד הבריאות (כ-4,600 מזונות בעברית, נמצא בתוך האפליקציה ועובד בלי אינטרנט). בוחרים מזון, כמות ויחידה (גרם / כוס / פרוסה / יחידה...) והערכים מחושבים אוטומטית.
  - **סריקת ברקוד** (כפתור המצלמה) של מוצרים ארוזים דרך Open Food Facts — מאגר פתוח וחינמי, דורש אינטרנט. בפעם הראשונה האייפון יבקש אישור גישה למצלמה.
    אם המוצר לא נמצא — מזינים פעם אחת את הערכים מהתווית (ל-100 גרם) והוא נשמר.
  - **המזונות שלי** — כל מוצר שנסרק או שיצרת נשמר, מופיע ראשון בחיפוש ונסרק גם בלי אינטרנט. ניהול ומחיקה בהגדרות.
  - **אכלת לאחרונה** — כפתורים להוספה חוזרת מהירה, עם אותה כמות כמו בפעם הקודמת.
  - **הזנה ידנית** — לארוחה במסעדה וכדומה.
- **נתונים** — בחירת תקופה (השבוע / החודש / 30 יום / 3 חודשים / שנה / הכל):
  כמה אימונים מכל סוג, סטים ונפח, ק"מ, מספר ריצות, קצב ממוצע, ריצה ארוכה, ממוצע קלוריות וחלבון,
  גרפים של 8 השבועות האחרונים, וגרף התקדמות לכל תרגיל (שיא משקל).

## עיצוב

עיצוב "מחברת אימונים" (נבנה עם הסקיל Impeccable): נייר משובץ, דיו קבוע לכל תחום (כחול לכוח, ירוק לריצה, כתום לאוכל), ספירות כקווי ספירה בעט, ואדום רק לשיאים ויעדים. במצב כהה של האייפון האפליקציה עוברת אוטומטית לגרסת ערב. כללי העיצוב המלאים: `DESIGN.md` בתיקיית הפרויקט.

## מקורות נתונים

- מאגר התזונה הלאומי — משרד הבריאות, data.gov.il (ערכים ל-100 גרם + יחידות מידה).
- Open Food Facts — openfoodfacts.org (מאגר פתוח לברקודים). כשסורקים, רק מספר הברקוד נשלח לשם.
